# Project GIFs Directory

This directory contains GIF files that showcase your projects in action. Each project on the projects page will look for a corresponding GIF file here.

## Expected GIF Files

The following GIF files are expected for the projects page:

- `uav_landing.gif` - Demo of the Autonomous UAV Landing System
- `slam_integration.gif` - Demo of Semantic SLAM Integration
- `iot_energy.gif` - Demo of IoT Energy Optimization
- `visual_navigation.gif` - Demo of Visual Navigation for Aerial Robots
- `website_demo.gif` - Demo of the Personal Website
- `speedcubing_app.gif` - Demo of the Speedcubing Timer App
- `robotic_manipulation.gif` - Demo of the Robotic Manipulation System
- `ai_research_assistant.gif` - Demo of the AI-Powered Research Assistant

## GIF Requirements

- **Dimensions**: Recommended 400x300 pixels or similar aspect ratio
- **File size**: Keep under 5MB for good loading performance
- **Duration**: 3-10 seconds works best for showcasing features
- **Quality**: Balance between quality and file size

## Fallback Behavior

If a GIF file is not found, the page will automatically fall back to displaying the original Font Awesome icon for that project.

## Adding New Projects

When adding new projects to the projects page:

1. Add the corresponding GIF file to this directory
2. Update the projects page HTML to reference the new GIF
3. Add the filename to this README for documentation
